# Security policy

## Supported versions

Security fixes target the latest released version of `@dagim_codes/sheriff`. Older versions and release lines are not maintained. Update to the latest release when a fix becomes available, following any migration instructions in its release notes.

## Report a vulnerability privately

Use GitHub's [Report a vulnerability](https://github.com/dagim-shimelis/sheriff/security/advisories/new) form. Do not open a public issue or PR containing exploit details before a fix and disclosure plan have been agreed.

Include:

- The affected Sheriff version, operating system, Node.js version, and host integration.
- A description of the impact and the conditions needed to reproduce it.
- Minimal reproduction steps or a proof of concept using a disposable project.
- Any suggested mitigation.

Remove credentials, personal data, and private source code from attachments and logs. Use only systems and data you are authorized to test.

The maintainer will investigate through the private report and coordinate a fix and disclosure with the reporter. There is no guaranteed response time.

For ordinary bugs and feature requests, use [GitHub issues](https://github.com/dagim-shimelis/sheriff/issues). For conduct concerns, see the [Code of Conduct](CODE_OF_CONDUCT.md).
